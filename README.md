# EAI-Learning

具身智能 · 现场认知笔记

> 湘潭理工学院 · 车辆工程 · 2028 届 ｜ 2026.11 起

## 这个仓库是什么

记录我在具身智能机器人现场看到的现象、做过的排查、弄懂的概念。
**不写算法复现，不抄论文摘要**——只写"我亲眼见过、亲手做过"的部分。

和另一个仓库的分工：

| 仓库 | 内容 | 目的 |
|---|---|---|
| [python-lab](https://github.com/zz11424/python-lab) | Python 工具链、脚本 | 学会用工具处理数据 |
| **EAI-Learning**（本仓库） | 机器人现场、故障、概念、话术 | 建立对具身智能落地的判断力 |

## 使用方式

1. 每周至少往 `journal/` 写一次，三行也算。
2. 每搞懂一个新词，往 `glossary.md` 加一条，必须写"在哪看到的"。
3. 三个月后回看，这里就是简历和面试的全部素材。
