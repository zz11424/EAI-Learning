# 书单

> 只列能读完的。每本标注"读哪几章"，读完再换下一本。

## 1. 《丰田生产方式》——对应现场 SOP 与动作拆解

- 读：**标准作业**、**准时化** 两章
- 为什么：你每天在按 SOP 做动作、记耗时，这本书讲的就是"怎么把动作标准化、怎么消除浪费"
- 读完能回答：为什么标准作业要写"节拍、顺序、标准手持"三要素

## 2. 《图解机器人学》——对应自由度、运动学

- 读：**自由度**、**工作空间** 两章
- 为什么：现场听到的"6 轴""腕部奇异""够不到"都能对上
- 读完能回答：为什么球形腕能让姿态解算变简单

## 3. 《利用 Python 进行数据分析》——对应数据管线

- 暂缓，等你想把动作卡变成指标表时再看
- 只看：**pandas 入门**、**数据清洗** 两章
- 为什么：你现在的 Python 水平还接不住，先放着

## 不推荐现在读的

- 强化学习教材（CS285 之类）：你现在用不上，读了也记不住
- 论文（ACT / Diffusion Policy）：等你能说清楚"数据怎么采"再看
- 任何"XX 天精通"的课：不解决问题，只消耗时间

## 阅读节奏

每周 1 次，每次 30 分钟，只读标注的章节，读完写 3 行到 `journal/`。
**读完一本再买下一本。**
